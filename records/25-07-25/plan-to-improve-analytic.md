사용자 분석 페이지 개선 계획                                                                           │ │
│ │                                                                                                        │ │
│ │ 현재 분석 기능의 주요 누락 부분을 보완하여 MVP 수준의 종합적인 사용자 분석 대시보드를 구축하겠습니다.  │ │
│ │                                                                                                        │ │
│ │ 1단계: 핵심 누락 지표 백엔드 구현 (우선순위: 높음)                                                     │ │
│ │                                                                                                        │ │
│ │ - 유입 경로 분석: 트래픽 소스 추적 및 분석 서비스 구현                                                 │ │
│ │ - 세션 분석: 평균 세션 시간, 페이지/세션, 시간대별 분석                                                │ │
│ │ - 페이지별 성과: 인기 페이지, 진입/이탈 페이지 분석                                                    │ │
│ │ - 디바이스/브라우저 분석: User-Agent 기반 디바이스 분류                                                │ │
│ │                                                                                                        │ │
│ │ 2단계: 사용자 행동 추적 개선 (우선순위: 높음)                                                          │ │
│ │                                                                                                        │ │
│ │ - User Flow 추적: 페이지 간 이동 경로 분석                                                             │ │
│ │ - 검색 행동 분석: 검색어, 결과 클릭률, 성공률 추적                                                     │ │
│ │ - 상세 퍼널 분석: 가입/콘텐츠 작성/참여 퍼널의 세분화                                                  │ │
│ │                                                                                                        │ │
│ │ 3단계: 프론트엔드 대시보드 확장 (우선순위: 중간)                                                       │ │
│ │                                                                                                        │ │
│ │ - 트래픽 소스 차트: 유입 경로별 시각화                                                                 │ │
│ │ - 지역별 사용자 맵: 지역 분포 히트맵                                                                   │ │
│ │ - 디바이스/브라우저 분포: 파이차트 및 트렌드                                                           │ │
│ │ - 페이지 성과 테이블: 정렬/필터 가능한 상세 테이블                                                     │ │
│ │                                                                                                        │ │
│ │ 4단계: 고급 분석 기능 (우선순위: 중간)                                                                 │ │
│ │                                                                                                        │ │
│ │ - 코호트 분석: 월별 신규 사용자 리텐션 분석                                                            │ │
│ │ - 실시간 사용자 현황: 현재 접속자 및 활동 모니터링                                                     │ │
│ │ - 성능 지표 통합: Core Web Vitals 연동                                                                 │ │
│ │                                                                                                        │ │
│ │ 5단계: GA4 통합 강화 (우선순위: 낮음)                                                                  │ │
│ │                                                                                                        │ │
│ │ - GA4 Reporting API: 실제 GA4 데이터 연동                                                              │ │
│ │ - 자동 인사이트: AI 기반 분석 결과 해석                                                                │ │
│ │ - 커스텀 대시보드: 사용자 정의 위젯 구성                                                               │ │
│ │                                                                                                        │ │
│ │ 각 단계는 점진적으로 진행하여 기존 기능을 유지하면서 새로운 지표를 추가하는 방식으로 구현하겠습니다.
