## 📋 개요

이 문서는 입주 서비스 업체 페이지의 포괄적인 테스트 시스템 사용법을 안내합니다. 

### 🎯 테스트 시스템 구성

1. **자동화 API 테스트** - 백엔드 API 완전 자동화 테스트
2. **브라우저 확인 테스트** - 프론트엔드에서 직접 확인하는 수동 테스트
3. **테스트 데이터 관리** - 테스트 데이터 생성/정리 자동화

### 🔐 입주 서비스 업체 페이지 특별 기능

- **권한 시스템**: 글쓰기 권한을 가진 사용자만 게시글 작성 가능
- **문의/후기 댓글**: `service_inquiry` (문의), `service_review` (후기) 분류
- **비공개 문의**: 문의 작성 시 비공개 옵션으로 내용 마스킹 처리
- **별점 평가**: 후기 작성 시 1-5점 별점 시스템 포함
- **확장 통계**: 문의/후기 분류별 실시간 통계 집계

## 🤖 1. 자동화 테스트 실행

### 1.1 사전 준비

```bash
# 백엔드 서버 실행 확인
cd backend
uv run python main.py

# 다른 터미널에서 자동화 테스트 실행
cd scripts/development/testing/api
```

### 1.2 자동화 테스트 실행

```bash
# 기본 자동화 테스트 실행
python service_provider_api_automation_test.py

# 실행 예상 시간: 약 15-20분
```

### 1.3 테스트 결과 확인

자동화 테스트 완료 후 다음 파일들이 생성됩니다:

```
reports/
├── service_provider_test_report_YYYYMMDD_HHMMSS_XXXX.json  # JSON 보고서
└── service_provider_test_report_YYYYMMDD_HHMMSS_XXXX.html  # HTML 보고서
```

#### HTML 보고서 확인 방법

```bash
# 브라우저에서 HTML 보고서 열기
# 터미널에 출력된 file:// URL을 브라우저에 붙여넣기
```

### 1.4 자동화 테스트 항목

1. **기본 인프라 검증** (30초)
   - 서버 헬스체크
   - 인증 시스템 검증
   - 기본 API 응답 확인

2. **권한 시스템 검증** (1분 30초)
   - 권한 사용자 인증 확인
   - 권한 없는 사용자 차단 검증
   - 권한 기반 게시글 작성 테스트

3. **서비스 업체 게시글 기능** (2분)
   - 서비스 업체 목록 조회
   - 서비스 상세 조회 및 확장 통계
   - 권한 기반 게시글 CRUD

4. **문의/후기 댓글 시스템** (3분 30초)
   - 문의 댓글 CRUD (service_inquiry)
   - 후기 댓글 CRUD (service_review)
   - 댓글 서브타입 분류 검증

5. **비공개 문의 마스킹** (2분)
   - 비공개 문의 작성
   - 작성자 원본 내용 조회
   - 타 사용자 마스킹 처리 확인

6. **별점 평가 시스템** (2분)
   - 별점 평가 입력 (1-5점)
   - 별점 평균 계산 검증
   - 별점 통계 실시간 업데이트

7. **확장 통계 검증** (2분 30초)
   - 문의/후기 분류별 통계 정확성
   - 실시간 통계 업데이트 확인

8. **데이터 정리** (30초)
   - 세션별 테스트 데이터 식별
   - 안전한 데이터 삭제

## 🛠️ 6. 문제 해결 가이드

### 6.1 자동화 테스트 관련 문제

#### Rate Limiting 오류
```
⚠️ Rate limit 감지 - 대기 시간을 15.0초로 증가
```
**해결법**: 테스트가 자동으로 대기 시간을 조정하므로 그대로 대기

#### 서버 연결 실패
```
❌ 서버 연결 실패: Connection refused
```
**해결법**: 
1. 백엔드 서버 실행 상태 확인
2. 포트 8000 사용 여부 확인
3. 데이터베이스 연결 상태 확인

### 6.2 브라우저 테스트 관련 문제

#### 테스트 데이터가 보이지 않음
**해결법**:
1. `service_provider_browser_test_setup.py` 재실행
2. 세션 ID 확인: `python service_provider_test_data_manager.py --list`
3. 브라우저 캐시 클리어

#### 권한 사용자 로그인 안됨
**해결법**:
1. 테스트 데이터 생성 로그에서 이메일 주소 확인
2. 비밀번호는 기본값 사용 (보통 'password' 또는 'test123')
3. 데이터베이스에서 사용자 생성 상태 확인

#### 비공개 문의 마스킹이 작동하지 않음
**해결법**:
1. 다른 사용자 계정으로 로그인했는지 확인
2. 로그아웃 후 확인
3. 브라우저 개발자 도구에서 API 응답 확인

### 6.3 데이터 정리 관련 문제

#### 일부 데이터가 삭제되지 않음
**해결법**:
1. `--dry-run`으로 삭제 대상 확인
2. 세션 ID 정확성 확인
3. 수동으로 데이터베이스에서 확인

#### 기존 데이터가 삭제됨
**예방법**:
1. 항상 `--dry-run`으로 먼저 확인
2. 세션 ID를 명시적으로 지정
3. 정기적으로 데이터베이스 백업
